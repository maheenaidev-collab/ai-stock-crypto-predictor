## ⚠️ Disclaimer

This project is for **educational purposes only**. It is NOT financial advice. Stock and crypto markets are unpredictable. Never invest based solely on ML predictions. Always do your own research.

## 🚀 Features

- **Multi-Asset Support** — Stocks (AAPL, TSLA, GOOGL) & Crypto (BTC, ETH, DOGE)
- **Multiple ML Models** — Linear Regression, Random Forest, LSTM Neural Network
- **Technical Indicators** — RSI, MACD, Bollinger Bands, Moving Averages, Volume Analysis
- **Price Prediction** — Predict next 1-30 days price movement
- **Trend Classification** — Bullish, Bearish, or Neutral signals
- **Visual Charts** — Interactive price charts with predictions overlay
- **Backtesting** — Test model accuracy on historical data
- **Real-Time Data** — Fetches live market data via Yahoo Finance API
- **Model Comparison** — Compare accuracy across different models
- **Export Reports** — Save predictions and analysis to CSV/JSON
